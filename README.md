# Proyectos web · Daniel Ruiz

Portafolio estático para GitHub Pages.

- `index.html`: selección de proyectos; Nocturne Shadows se identifica como marca y proyecto propio.
- `detallado.html`: demostración Brillo Estudio, un negocio ficticio de detallado automotriz.
- `hero.jpg`: imagen ilustrativa generada con IA para la demostración.
- `.nojekyll`: publicación estática sin procesamiento Jekyll.

La demostración no envía mensajes, no almacena datos y no representa un cliente contratado. El sitio real de Nocturne Shadows se visita mediante su enlace externo.
